# Radiant Run 005 — v0.6

## Objective
Test whether the sequencing regime-adaptation result generalizes, and build a causal method that can decide when short-memory adaptation is warranted rather than assuming it.

## Work completed
- Added a second real measured domain: 11 annual global lithium-ion battery pack-price observations, 2010–2020, transcribed from NREL's H2 2020 Solar Industry Update (which cites BloombergNEF's 2020 survey).
- Tagged the entire battery series as retrospective and source-available in 2021. Strict replay before publication therefore returns zero rows by construction.
- Reused the exact generic forecasting/backtest machinery without battery-specific semantic changes.
- Falsified the hypothesis that the sequencing surprise/adaptation rule is generally superior.
- Added `causal_model_selector`: a prequential selector among all-history and finite rolling windows. It chooses the next model only from errors already observed before the target outcome.
- Added an anti-leakage test that changes the final target by 100x and verifies the model choice for that target is unchanged.

## Quantitative results
### DNA sequencing
- all-history MALE: 0.7836
- rolling-8: 0.2744
- previous adaptive rule: 0.2084
- causal selector: **0.1762**, median factor error **1.128x**

### Battery pack prices
Six held-out annual predictions after five training observations:
- all-history MALE: **0.1344**
- rolling-5: 0.1648
- sequencing-style adaptive: **0.1765**
- causal selector: 0.1461, median factor error 1.155x

The adaptive rule is ~31% worse than all-history on battery. This is a useful negative result: a regime detector that helped sequencing should not be promoted to a universal law.

The causal selector sacrifices a small amount versus the best battery model while substantially improving sequencing versus the prior adaptive rule. This is not yet enough evidence to claim cross-domain superiority; it is a safer architecture for learning which memory scale works.
