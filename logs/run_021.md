## Negative results / rejected approaches

2. "Nearly triple" is qualitative relative evidence and is not encoded as a numeric multiplier.
3. A planned 57 units/year site target is not relabeled as observed current production or national capacity.
4. Initial implementation overwrote the existing intervention partial-identification API, causing 2 test failures; restored the old API and extended rather than replaced it.
