# Run 008 — Transformer uncertainty and identifiability

## Objective
Replace the v0.8 point-scenario ranking with an uncertainty-aware layer and determine whether public evidence currently supports a real U.S. LPT bottleneck claim.

## Starting state
v0.8; 41 tests; evidence-backed transformer topology but normalized capacities. Binding gap: parameter identification.

## Primary evidence added
- DOE 2024 LPT Resilience Report: 2019 U.S. demand for new transformers >60 MVA ~750 units; >80% imported; cited expectation ~900 units/year by 2027; acquisition lead times commonly 36 months and up to 60 months.
- DOE Office of Electricity 2026 presentation: limited LPT interchangeability (~1.3 made per design), plus continuing import dependence.

## Code
Added `radiant/engines/uncertain_constraints.py` with interval-valued epistemic inputs, deterministic Monte Carlo, probabilistic intervention rankings, positive-gain probabilities, expected gains, throughput quantiles, and measurement-priority diagnostics. Added three falsification/reproducibility tests.

## Adversarial result
Using deliberately broad normalized intervals because measured stage capacities remain unavailable (all process capacities 0.45–1.35; material import limits 0.55–1.55), 300 fixed-seed draws yield throughput q05/median/q95 = 0.461/0.569/0.770. Best +20% intervention probabilities: assembly 19.0%, winding 18.3%, insulation preparation 16.7%, core fabrication 15.3%, testing 12.0%, GOES 7.0%, insulation 6.0%, CTC copper 5.7%.

## Interpretation
No intervention is robustly identified. This falsifies any temptation to turn DOE's qualitative vulnerability statements into a numerical claim that GOES, testing, assembly, or another stage is *the* current U.S. binding constraint. The engine now returns epistemic ambiguity instead of false precision.

## Tests
44/44 passing.

## Weakest link / exact next action
Acquire stage-level measurements: plant capacity/utilization, cycle times/WIP, test-bay throughput, winding/core equipment utilization, actual order/specification microdata, and material allocation/shortage observations. Build an observation schema for procurement records and use lead-time/order outcomes to infer latent capacity constraints. Standardization should be modeled as a candidate intervention only after an empirically defensible mapping from design variety to setup/cycle time is obtained.
