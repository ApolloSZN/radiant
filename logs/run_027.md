## Code/schema differences

### Fair-baseline gate

Before: sequencing passed if MALE improved >=50% versus an all-history trend.

After: sequencing passes only if the selector robustly beats **every** member of the predeclared simple-baseline panel. The strongest observed panel member is reported explicitly. The old all-history comparison remains in diagnostics for provenance but cannot satisfy the ship gate.

### Online aggregation benchmark

Predeclared experts:

- all-history
- rolling-8
- rolling-6
- rolling-5
- rolling-4
- rolling-3
- no-change

Algorithms:

- follow-the-leader using only prior observed absolute log losses;
- exponential weights using only cumulative prior loss with deterministic `eta_t = sqrt(8 log(K) / t)`.

No current target is used to form its own forecast. No learning-rate search was conducted against the outcome.

### GOES code coverage

Coarse identity remains two HS-6 headings, but direct current U.S. imports now require all four current Commerce/SIMA HTSUSA-10 codes:

- 7225110000
- 7226111000
- 7226119030
- 7226119060

Current exports use the separate Commerce export concordance:

- 7225110000
- 7226110000

The code sets carry classification, direction, source and effective-period metadata. Aggregation fails if a required code is absent rather than silently treating absence as zero.
