# Run 010 — Radiant v0.11

## Objective
Turn transformer expansion announcements and DOE manufacturing evidence into falsifiable capacity-sufficiency statements while refusing unsupported stage-level causal claims.

## Work completed
Added `transformer_expansion.py`, three falsification/unit tests, migration 006 for constraint hypotheses/evidence bindings/capacity additions, and five new transformer evidence records. DOE primary evidence establishes shared finite build slots, 1–3 year new-factory construction, 1–2 year specialty equipment procurement, widespread skilled-labor difficulty, and test-space as a plausible bottleneck-relief mechanism. APPA's report of Siemens' Charlotte announcement provides the first public unit-rate addition used here: 24 new LPT/year initially, 57/year at full rate. Hitachi's $457m South Boston project is persisted as evidence but assigned no fabricated units/year.

## Quantitative result
2019 implied domestic nameplate from the prior Commerce/DOE accounting is 342.5 units/year. Adding Siemens' disclosed 57/year full rate gives 399.5. Against a deliberately static 750-unit benchmark, 100% utilization of both still leaves 350.5 units/year of external supply and yields only a 53.27% domestic nameplate upper bound. This is an optimistic accounting bound, not a forecast or feasible-output estimate.

DOE's ~900 units/year 2027 demand anchor uses a >60 MVA category while the legacy Commerce accounting uses >100,000 kVA. The engine therefore labels the corresponding 500.5-unit residual as a cross-definition scenario, not an identified gap.

## Negative result retained
The 89% workforce-hiring-difficulty statistic is strong evidence that labor is a widespread constraint candidate, but it cannot identify labor as the binding marginal constraint. Likewise DOE's statement that more test space could ease bottlenecks is directional, not an effect size. Radiant does not rank these interventions from those facts alone.
