# Run 009 — v0.10

## Objective
Turn transformer uncertainty into defensible partial identification and extract any real conclusion supported by existing macro evidence without inventing stage parameters.

## Starting state
v0.9, 44/44 tests. Uncertainty ensembles showed no robust stage-level bottleneck; parameter identification was binding.

## Sources added
- U.S. Department of Commerce Section 232 transformer investigation, Federal Register publication 2021-11-18: 137 domestic >100,000 kVA units in 2019; GOES/lamination/core trade evidence.
- Wood Mackenzie 2024 transformer availability analysis: ~150-week ARO lead times.
- Wood Mackenzie 2025 press release: estimated 30% U.S. power-transformer deficit and ~80% import share.

## Build
- `radiant/engines/partial_identification.py`: distribution-free corner-set partial identification over bounded capacities/imports; reports throughput identified interval, intervention gain bounds, robust-positive and robust-best status.
- `radiant/data/transformer_macro.py`: evidence-backed 2019 accounting and a clearly labeled full-utilization counterfactual bound.
- Added tests for refusal of fake identification, successful identification when bounds genuinely isolate one bottleneck, and 2019 macro arithmetic.
- Added evidence rows to transformer evidence ledger.

## Quantitative outputs
2019: apparent consumption = 137 + 617 - 4 = 750 units; import share = 82.27%. Reported ~40% utilization implies ~342.5 units/year nameplate capacity and ~205.5 unused capacity. Even assuming full utilization with no other constraints, imports needed to preserve 750-unit apparent consumption remain ~411.5 units/year. This is an accounting upper bound, not a production feasibility estimate.

## Negative/null result retained
Existing public macro evidence still cannot distinguish labor vs material vs winding/core/test vs customization/qualification as the marginal domestic production constraint. No stage-level recommendation is issued.

## Architectural decision
Use partial identification before probabilistic uncertainty whenever evidence supports bounds but not a defensible distribution. Monte Carlo remains scenario analysis unless distributions have empirical provenance.

## Adversarial direction check
Improved empirical grounding, falsifiability, and epistemic validity. The run extracted one consequential macro conclusion while narrowing what cannot yet be claimed.

## Weakest link / exact next action
Build an order/plant evidence table from public utility procurement awards, manufacturer expansion disclosures, Commerce/USITC/NLR capacity-utilization series, and qualification/design evidence. Seek natural variation that can explain lead time/output conditional on design and vendor. Then estimate identified effects or bounds for standardization, labor/capacity expansion, and import substitution.
