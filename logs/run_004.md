# Run 004 — historical evidence vintage + causal regime adaptation

## Objective
Attack the binding historical-vintage constraint and implement a no-lookahead surprise detector that can alter only future forecasts.

## Work completed
- Added `data/nhgri/historical_vintage_anchors.csv` with five contemporaneous NHGRI primary-source anchors (2006, two 2010 statements, 2011, 2012), preserving source publication availability separately from observation date.
- Added `VintageAnchor`, `load_vintage_anchors`, and `historical_vintage_as_of`.
- Added sequential innovation z-score regime-break detection. Each target is scored only from observations preceding it.
- Added a causal adaptive forecaster: a detected surprise can shorten the fitting window only for subsequent predictions.
- Added 3 tests covering vintage visibility, no-lookahead break detection, and adaptive reproducibility.

## Quantitative results
47-row retrospective NHGRI series, 39 held-out one-step predictions:
- all-history MALE 0.783606; median factor error 1.91571x
- rolling-8 MALE 0.274382; median factor error 1.19279x
- adaptive causal MALE 0.208373; median factor error 1.16617x
The simple adaptive policy reduces MALE 24.06% versus rolling-8 and 73.41% versus all-history on this retrospective series.

At |z| >= 2, sequential surprise flags include 2007-10, 2008-01, 2008-04, 2008-07 during the NGS discontinuity, but also several pre/post-transition flags. Therefore this is evidence that causal adaptation can improve this series, NOT evidence that the current detector is calibrated or generally valid.

## Failure / honesty boundary
Gate 1 is still NOT passed. Five dated narrative anchors are enough to exercise historical-vintage semantics but not enough to reconstruct the full information set available at each historical cutoff. Current 47-row numerical series remains retrospectively transcribed. The adaptive benchmark is therefore a retrospective no-lookahead algorithmic test, not a strict historical-vintage backtest.
