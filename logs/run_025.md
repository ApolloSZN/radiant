# Run 025 — v0.14-rc13

## Starting state
v0.14-rc12 / Run 024; 90 tests green; release 9/11.

## Objective
Begin the authoritative vintage-tagged GOES supply-response panel while preventing commodity-code incompleteness and vintage mismatch from creating a false adequacy result.

## Sources consulted
- U.S. Census Schedule B: GOES is separately classified at 7225.11 (width >=600 mm) and 7226.11 (width <600 mm), both reported in kg.
- U.S. Census FT900 steel data documentation: current and historical detailed import datasets are available and are an authoritative ingestion path.
- Commerce Section 232 GOES/transformer investigation: retained 2019 historical anchors (~220 kt apparent consumption; ~27 kt imports).
- USGS Mineral Commodity Summaries 2026/data release: reviewed but rejected as a GOES-specific supply substitute because its iron-and-steel aggregates do not identify GOES production response.

## Implementation
Added `radiant/data/goes_supply_panel.py` with typed vintage observations, canonical GOES width-code coverage, a fail-closed trade-coverage validator, descriptive 2019 import-share calculation, and a machine-readable adequacy-identification contract.

## Quantitative outputs
- Commerce 2019 descriptive imports/apparent-consumption ratio: 27/220 = 12.27%.
- This ratio is historical context only and is not promoted to future import capacity or import reliance.
- Adequacy remains unidentified because compatible 2026+ domestic production/capacity, exports, inventory/stock change, and competing-consumption bounds are absent.

## Failures / rejected approaches
- Rejected using only HTS/Schedule-B 7225.11: it omits GOES narrower than 600 mm (7226.11).
- Rejected aggregate USGS iron/steel capacity as GOES capacity.
- Rejected carrying the 2019 import share forward as a 2026+ supply-response assumption.
