# Run 020 — v0.14-rc8

## Objective
Parameterize a real LPT production-network slice using primary/public evidence without converting qualitative facts into invented coefficients.

## Evidence consulted
- U.S. DOE, *Large Power Transformer Resilience Report to Congress*, July 2024: production-input graph; GOES/CTC importance; roughly 25% production-cost shares each; majority of GOES used for U.S. LPT manufacture not domestic; lead times up to/exceeding 36 months.
- U.S. DOE, *Electric Grid Supply Chain Deep Dive Assessment*, 2022: LPT production structure; testing can take about one week; stakeholder evidence of facilities with 1–2 test beds; testing space can constrain output; 2019 import dependence and utilization context.

## Implementation
Added `radiant/data/lpt_evidence_network.py`, representing the real documented material→component→assembly→testing graph. Measured facts are stored separately from seven explicitly unknown physical/capacity parameters. Added structural knockout claims that say only what topology licenses: removal of a documented necessary path element breaks that represented path; the magnitude is not identified.

## Negative result / rejected approach
The public sources do not provide a mutually compatible set of GOES mass/LPT, CTC mass/LPT, insulation mass/LPT, and annual core/winding/assembly/testing capacities. Therefore an empirical period-resolved LP cannot yet be honestly parameterized. Cost shares (~25%), lead times (>36 months), import dependence, and test-bed counts were explicitly rejected as substitutes for physical throughput coefficients.

## Tests
76/76 green. New tests ensure the empirical slice is labeled topology-identified but numeric-path-unidentified and that structural knockout language never becomes an effect size.

Improved empirical grounding, physical validity, and falsifiability. It also exposed the binding data gap rather than hiding it behind scenario numbers.

## Weakest link
Compatible numeric production coefficients / bounded stage capacities and real causal intervention outcomes.
